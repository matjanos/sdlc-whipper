# Code of Conduct

Whipper should be a friendly place to build reliable software-delivery infrastructure.

Be respectful, specific, and generous in technical discussion. Critique ideas and code—not people. Harassment, discrimination, threats, and deliberate disruption are not acceptable in project spaces.

Maintainers may edit or remove harmful content and restrict participation when necessary to protect the community. To report conduct privately, contact a maintainer through their GitHub profile and request a private channel.
